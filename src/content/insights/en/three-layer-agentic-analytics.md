Andrey describes a three-layer setup for analytics work: a voice assistant helps shape tasks and review results; an autonomous agent works through a shared task queue and returns prototypes; an interactive agent supports hands-on analysis and review.

The post emphasizes that autonomy does not remove human oversight. The agents operate within defined tool access, and high-stakes changes to long-running data pipelines remain under human control.
